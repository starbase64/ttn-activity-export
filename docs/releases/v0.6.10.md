# TTN Activity Export 0.6.10 · Update mit OK/Abbrechen

Diese Version ergänzt selbst ausgeführte Updates für den Windows-x64-Starter. Sie muss einmal manuell entpackt und gestartet werden, weil ältere App-Versionen den Update-Helfer noch nicht enthalten. Danach fragt eine neuere veröffentlichte passende Version nach **OK** oder **Abbrechen**. Mit OK lädt die App das Paket, prüft es, beendet sich, richtet die neue Version ein und startet sie automatisch. Bei Abbrechen bleibt die bisherige Version aktiv.

Laufende Downloads, Exporte und GPS-Lesevorgänge werden nicht für ein Update unterbrochen. Pakete werden anhand des von GitHub gelieferten SHA-256-Digests und der enthaltenen Dateiprüfsummen geprüft. Die neue Version wird separat eingerichtet und vor der Umschaltung getestet. Die bisherige Installation bleibt als Rückfall erhalten. Bestehende Verknüpfungen, Konten, Einstellungen und Datenordner bleiben nutzbar. Alte Programmversionen bleiben auf dem Datenträger; für die zusätzliche private Laufzeit wird freier Speicher benötigt. Die verifizierten Installationspakete werden aus dem bisherigen Cache wiederverwendet.

Das automatische Installieren gilt für diese neue Windows-Starter-Installation. Quellcode- und EXE-Installationen behalten **Download öffnen**. Es werden vollständige kleine App-Pakete verwendet; binäre Delta-Patches folgen separat. Der Button „Exportcache übernehmen“ erscheint nur bei einem ausgewählten Garmin-Konto. Bei Komoot, Strava und ohne Konto ist er ausgeblendet. Bereits erfolgreich importierte Daten werden aus der Offline-Datenbank gelesen; dafür ist der alte Cache nicht mehr nötig.

English: install this Windows starter manually once. Future matching releases can then be installed with OK/Cancel. The app verifies the GitHub asset SHA-256, package manifest and app version, closes, tests the separate new runtime/app and restarts through the same launcher. Previous program folders and user data are preserved for fallback. Running jobs are not interrupted. Older/source/EXE installations retain manual downloads. No delta patching yet. The Garmin export-cache import button is hidden for other providers and when no account is selected. Successfully imported records remain usable from the offline database without the old cache.
