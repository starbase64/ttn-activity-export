# TTN Activity Export 0.6.11-preview · Update-Helfer zuverlässig starten

Der automatische Start des Windows-Update-Helfers in 0.6.10 wurde in einem zusätzlichen Windows-Test als fehlerhaft reproduziert: Das Skript wurde gar nicht ausgeführt, obwohl der Download abgeschlossen war und die App sich beendet hatte. Der manuelle Start mit plan.json funktionierte. Diese Testversion korrigiert die Prozess-Erstellung und startet Windows PowerShell ohne Konsolenfenster mit expliziten, nichtinteraktiven Argumenten.

Die App bleibt während der Übergabe geöffnet, bis der Helfer seinen Start mit passendem Vorgangsschlüssel und Prozess-ID bestätigt. Erst dann beendet sie sich. Bei frühem Prozessende, fehlender Bestätigung oder Startfehler bleibt die App geöffnet und zeigt den Protokollordner an. Launch-Versuch, Prozess-ID und Fehler werden in helper-output.log protokolliert. Fehlgeschlagene Übergaben behalten die vorbereiteten Dateien und Logs.

Diese Vorschau einmal manuell in einen neuen Programmordner entpacken und über Start-TTN-Activity-Export.cmd starten. Ein noch fehlerhafter alter Starter kann seine eigene Startfunktion nicht durch ein heruntergeladenes Paket reparieren. Konten, Einstellungen und Daten bleiben im bisherigen Profil beziehungsweise Datenordner. Öffentliche Version 0.6.10 bleibt unverändert.

English: the 0.6.10 app-created detached helper failed to enter PowerShell in a native regression, while manual installation succeeded. This preview uses a windowless, noninteractive system PowerShell launch and waits for a matching startup acknowledgement before closing the app. Startup failure keeps the app open and preserves update diagnostics. Launch attempts, PID and errors are recorded. Install this preview manually in a new program directory once; public release 0.6.10 stays unchanged.
